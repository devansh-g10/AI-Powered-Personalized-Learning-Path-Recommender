| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **AI-Powered Personalized Learning Path Recommender** seriously.

If you believe you have found a security vulnerability, please **do not open a public GitHub issue**. Instead, report it privately:

1. **Email:** Send details of the vulnerability to [devanshmaheshwari3011@gmail.com](mailto:devanshmaheshwari3011@gmail.com).
2. **Details to include:**
   - Type of vulnerability (e.g., SQL injection, XSS, token leakage, auth bypass).
   - Step-by-step instructions to reproduce the issue.
   - Any potential impact or proof of concept (PoC).

We will acknowledge receipt of your vulnerability report within 48 hours and work on resolving it promptly.
